连接微信会话

先在微信中打开要接入的私聊或群聊。

需与当前私聊标题完全一致。请使用唯一备注，避免同名。

供 OneBot 框架识别的数字别名，不是微信号。发送目标使用这个 ID。

供 OneBot 使用的本地数字别名，不是微信群号。群回复使用这个 ID。

填写实际群昵称，AstrBot 才能识别可见文字中的 @机器人。请关闭 AstrBot 的「回复时 @ 发送者」及引用回复。

群成员按可见头像分配本地 ID，昵称可能显示为“群成员”。相同头像可能合并，换头像可能变更 ID；这里不能读取真实 wxid 或完整群成员名单。
02

接入机器人框架

已有 NoneBot 等框架时，填写它的反向连接地址。

每行一个地址。使用 HTTP API 或正向 WS 时可留空。

图片和文件由 AstrBot 下载。远程或容器部署时填写 AstrBot 能访问的本机地址，并设置服务监听地址。每个附件使用独立随机下载链接。

在机器人框架中填写相同令牌，即可通过鉴权。
